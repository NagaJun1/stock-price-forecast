# 日本株 株価予想アプリ

localhost で動く日本株 月次長期予想Webアプリ。公開プロキシを使わず、同梱サーバ経由で取得する。

## 目的

ブラウザ上で月ごとの長期予想値を参考情報として表示する。

## 機能要件

- 銘柄指定（証券コード。4桁数字は `7203` → `7203.T` に自動補完）
- 月足終値・直近値のブラウザ表示
- 先1〜24か月の予想終値の表示（既定12か月）
- 予想根拠の表示（使用モデル、前提条件）

## システム構成

- Runtime: Node.js 26以上（同梱サーバ用）
- 形態: 静的ページ＋データ転送だけの同梱サーバ（フレームワーク・外部依存なし）
- 言語: TypeScript（`src/browser.ts` が UI、`src/server.ts` がサーバ、`site/` 以下が公開物。`site/js/` はビルド生成物のため git 管理外）
- データ保存: なし（DB不使用）
- パッケージ管理: npm

## データソース

- 採用: Yahoo Finance chart API（v8）。ブラウザからは同一生成元の `/api/chart`、サーバが Yahoo に転送する（CORS 問題なし、公開プロキシ不要）
- 除外: J-Quants API（制約が大きく使いづらいため）
- APIキー不要

## 予想ロジック

1. ARIMA: 過去30年の月次終値に ARIMA(p,d,q) を当てはめ、AIC で次数選択して予測する（既定の探索範囲は p≦2、d≦1、q≦2）
2. 市場モデル（ファクター）: 日経平均（^N225）を市場ファクターとする単一ファクターモデル。銘柄の対数リターンを α＋β×市場リターンで回帰し、市場自体の将来値は ARIMA 予測から求める

結果は「月 | ARIMA | ファクター」の表で並べて出力する。

## 非機能要件

- データソースのレート制限対策（取得失敗時はエラーを明示して終了）
- エラー時は取得失敗を明示する

## セットアップ

```bash
npm install
npm run build
npm run serve
```

`http://localhost:3000` をブラウザで開く。証券コード（例: 7203）と予測月数を入力して「予測実行」を押す。ポート変更は `PORT=8080 npm run serve`。


## アプリで出力される内容

- 各月の終値
